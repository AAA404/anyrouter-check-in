AnyRouter / AgentRouter 配置生成器

填入两个账号的必要信息，生成可以直接粘贴到 GitHub Environment Secret ANYROUTER_ACCOUNTS 的 JSON。

安全提示：本页面不联网、不上传数据，也不会把内容保存到浏览器。GitHub Cookie 等同于登录凭据，请只在可信设备上使用，并在生成后清空页面。

AnyRouter · Session Cookie

需要填写 session 和 New-Api-User。

1

在 anyrouter.top 的开发者工具 → Application → Cookies 中复制 session 的值。

在 Network → Fetch/XHR 请求头中找到 New-Api-User，通常是一串数字。

AgentRouter · GitHub OAuth

粘贴 GitHub Cookie 导出 JSON，或 Cookie 请求头字符串。

2

推荐粘贴浏览器导出的完整 JSON 数组。也支持 user_session=...; logged_in=yes 格式。
